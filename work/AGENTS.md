# Work Profile

- Use authorized work accounts for work objectives; personal access requires an explicit request. Never mix the two or publish company hostnames, account details, local workspace paths, or credentials.
- For commits, verify the corporate Git identity in work repositories and the personal identity in confirmed personal repositories. Reuse existing checkouts.
- Keep tickets, PRs/MRs, review comments, and release notes short and factual: describe confirmed changes and impact, not agent activity or logs. Follow project review policy; write externally only when authorized.
